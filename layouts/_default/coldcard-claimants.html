Incident context

What happened?

Coinkite's published security advisories state that affected firmware versions used an unintended randomness path during seed generation. In plain terms, some seeds may have had materially lower entropy than intended.

Users have reported unauthorized on-chain movements from impacted wallets. Based on currently published technical analysis, this appears consistent with seed-predictability risk in affected configurations, rather than ordinary user mistakes alone.

Our intake is designed to help Coldcard victims document timelines, transaction evidence, and device context in a structured format so patterns can be reviewed and participants can receive coordinated updates.

Before you begin

Bring public evidence. Keep private secrets private.

A transaction hash is public blockchain data. Secret wallet credentials are not. Please only send what is needed to understand the incident.

OK to include

  • Transaction hash or transaction ID
  • Approximate amount lost
  • Date you first noticed the loss
  • COLDCARD model and setup context

Never include

  • Seed or recovery phrase
  • Private keys or wallet export files
  • Device PIN or wallet password
  • Any request to move your funds
